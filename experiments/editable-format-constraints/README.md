# Editable Format Constraints Experiment

This experiment validates the product contract for evidence-based LLM inferred format constraints that can be edited by the user before draft-processing uses them.

Key principle: StyleFacts remain deterministic facts; LLM rules are editable drafting constraints with evidence refs and hard safety gates.

Run:

```powershell
node experiments/editable-format-constraints/scripts/run-editable-format-constraints.mjs
```
