# 格式画像语义精炼约束: pptx-briefing

## 适用边界
- 文件类型：pptx
- 来源画像：profile_batch_16_pptx_github_01
- 本指令由 harness 根据确定性画像和已验收 LLM overlay 渲染；LLM 不直接生成最终指令。
- 保留来源事实边界，不根据格式画像虚构内容；不承诺版式还原或文件导出能力。

### 文档定位
- 汇报演示 （证据：raw.pptx.slide.0001）

### 结构组织建议
- 按逐页汇报叙事组织：封面/议题/主体/总结等页级边界。
- 保留 slideCount、layoutCount、masterCount 等线索，用于控制内容粒度。

### 样式/版式线索
- 版式、母版、主题和颜色线索用于提示页面节奏与正式程度。

### 写作约束
- 输出可转写到幻灯片的分页面底稿，每页聚焦一个观点。

### 格式边界
- PPTX 画像用于汇报底稿和页级结构建议，不代表会生成演示文件。

## 诊断边界
- 语义置信度：medium
- Harness 质量分：0.994
- 若用户事实材料与格式画像冲突，以用户事实材料为准，并记录诊断。
