## 格式约束（FormatSpec）

本次选择的格式画像类型为 PDF，定位为“成品参考/宣传介绍”。请只使用以下格式规则约束结构、表达和诊断，不要复制或补造来源文件正文内容。

### 必守边界
- 来源事实优先于格式约束。
- 不根据格式画像虚构事实、金额、条款、结论或引用。
- 不承诺导出或视觉还原。
- 如底稿事实与格式规则冲突，以底稿事实为准，并在诊断中说明。

### 详细格式规则
- 【page】PDF 以页为参考单位。 检测到页数 15；可参考篇幅和页面密度，但不反推完整可编辑模板。
- 【text-layer】文本层线索决定可参考程度。 文本层提示：存在；文本层不足时只做低置信参考。
- 【image-density】图片密度只作为版面复杂度诊断。 图片较多时，生成底稿应保持图文分区建议，不补造图片内容或位置。
- 【font-ref】字体引用不是可编辑字体承诺。 字体引用线索：YWSWBG+MicrosoftYaHei-Bold、UDUJXM+SegoeUI-Bold、YMVEVT+MicrosoftYaHei、LNUHNF+SimSun、VULAQV+SegoeUI；这些是 PDF 资源名，只能用于诊断。
- 【scan-risk】扫描风险影响置信度。 扫描风险：未明显触发；扫描风险高时不得输出细排版规则。
- 【reference-use】PDF 适合作为成品参考。 可参考页数、栏目密度、图文比例、正式程度；不把 PDF 当作可直接套用模板。
- 【boundary】PDF 画像不承诺视觉还原。 不能承诺跨页布局、图像位置、页眉页脚、印章、水印或装订效果。
- 【boundary】PDF 不产生来源事实。 任何正文、数据、引用和结论必须来自用户底稿或授权资料，不从字体/页面线索推断。

### 输出要求
- 输出低/中置信参考下的底稿或诊断，不反推 PDF 版式。
