# Wiki Precision + LongDoc 实验追踪目录

本目录是 `research/wiki-precision-longdoc` 分支的实验追踪主目录，用于避免把探索性记录混入主线计划区。

## 目的

- 独立追踪“完整精准 Wiki 生成 / 长文工程 / 精准定位 / 精准检索”的探索实验。
- 将实验计划、执行记录、结论、决策和后续任务集中管理。
- 不扰动当前 DOCX-first / format-profile 主线开发记录。

## 当前约定

- 研究性需求与最终汇报仍保留在 `.omx/plans/requirements/`，作为可被迁移计划引用的阶段性成果。
- 本目录作为实验主控面板，索引所有相关文档和实验产物。
- 后续新增实验优先在本目录登记，再写入 `experiments/wiki-precision-longdoc/` 执行产物。

## 关键入口

- 实验总览：`experiment-tracker.md`
- 决策记录：`decision-log.md`
- 执行记录索引：`run-log.md`
- 生产化候选任务：`handoff-tasks.md`
