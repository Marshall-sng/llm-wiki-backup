# PRD: Draft v1.2「底稿版本历史 + 基础对比」

## 目标

为底稿增加手动版本快照、基础对比和恢复为新底稿能力，降低直接编辑底稿时误删/误改后无法回退的风险，并为后续 diff guard、模板输出和导出版本确认打基础。

## 范围内

1. DraftRecord 增加运行时 `versions: DraftVersion[]`。
2. DraftRecord 增加可选 `restoration` 元数据。
3. 支持手动「创建版本快照」。
4. 支持选择历史版本并查看基础对比统计。
5. 支持「恢复为新底稿」。
6. 旧 drafts JSON 兼容加载。
7. 恢复来源在 UI 中明确显示为「由历史版本恢复生成」。
8. 大文本对比有阈值保护，避免 UI 卡顿。

## 范围外

- 不做自动快照。
- 不做完整 diff guard。
- 不做模板库。
- 不做模板生成。
- 不做 DOCX/PDF/Markdown 导出。
- 不做长文工程。
- 不新增依赖。

## 用户价值

- 用户可以在大改底稿前手动保存版本。
- 用户编辑后可以看到与历史版本的基础差异。
- 用户可以从历史版本恢复出新底稿，当前底稿不被覆盖。
- 后续正式导出可以绑定明确版本。

## 主要验收

- 旧底稿加载后 `versions` 可安全使用。
- 「创建版本快照」生成不可变版本记录。
- 编辑底稿不会自动制造版本噪音。
- 基础对比显示新增/删除/未变行数和变化比例。
- 「恢复为新底稿」生成新 Draft，原 Draft 不变。
- 恢复生成的新 Draft 显示恢复来源和父版本信息。
- 当前 AI 加工会话流程不变。
